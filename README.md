# Student Records

## About

I made this project to practice HTML, CSS and JavaScript.

The project displays student details in cards. It also has a search box to find students by name.

## What I Learned

- How to store data in an array of objects.
- How to use `map()` to transform student data into HTML cards.
- How to use `filter()` to search students by name.
- How to update the page using JavaScript.
- How to use button click events.

## `map()` Improvement

At first, I used `map()` for a side effect.

I changed it so `map()` returns an HTML card for each student. Then `join()` combines the cards before displaying them.

## Login Button

I added a simple Login button in the header and used JavaScript to handle its click event.

## How to Run

Open `index.html` in a browser.
